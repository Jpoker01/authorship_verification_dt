### Frontend app for authorship verification diploma thesis

This is a frontend application developed as part of a diploma thesis on authorship verification. The application provides a user-friendly interface for users to upload text samples and verify authorship based on various algorithms and models.

It has been built using the combination of React, TypeScript and Vite.
